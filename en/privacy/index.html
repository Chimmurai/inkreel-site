Privacy policy

Last updated: November 7, 2026

InkReel is a desktop app that runs entirely on your computer. It does not collect, transmit or sell any personal data. There are no accounts, ads, analytics or telemetry.

Your files

The app opens the videos, photos and GIFs you choose, reads them locally and writes the result where you tell it to. Files are never uploaded to any server and never leave your computer.

What is stored on your device

To work smoothly, the app keeps only local helper files:

  • settings (language, palette, processing options);
  • a technical log: app version, operating system, number of cores and amount of memory, library versions and error messages (an error message may include the name or path of the file being processed when it occurred);
  • compute and graphics-card selection caches that speed things up.

All of it lives in %LOCALAPPDATA%\InkReel (in the Store version, in the matching package folder under %LOCALAPPDATA%\Packages) and is never sent anywhere. You can delete these files at any time; uninstalling the app removes them (the installer asks separately about caches).

Network

The app does not need the internet to work and does not send data. The only connection is local, between running copies of the app on your own computer (so that a second launch can hand a file to the window that is already open).

If the build you installed outside the Store has a button to support the author, it only opens your browser on a third-party service’s page. From that moment that service’s policy applies; InkReel does not take payments and knows nothing about them. The Store build has no such button.

Third-party components

Open-source libraries run inside the app (including FFmpeg, ONNX Runtime, OpenCV, Pillow, NumPy and Numba). They run locally. Their licenses are in the app folder, in THIRD_PARTY_NOTICES.md and the licenses subfolder.

Children

The app collects no data about anyone, children included.

This website

The site inkreel.raimex.space is static and hosted on GitHub Pages. It has no cookies, analytics, ads, third-party fonts or scripts. Your palette choice, the light/shadow flip and the pen trail are stored only in your browser (localStorage) and are never sent anywhere.

If you pick your own photo or video in the demo, the file is processed only in your browser’s memory: it is never uploaded or stored.

Like any host, GitHub may keep technical request logs (for example, your IP address) under its own privacy policy. The site author neither receives those logs nor keeps any.

Changes

If this policy changes, the new version will appear on this page with a new date at the top.
